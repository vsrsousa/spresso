ESQUEMA DO BANCO PROVENANCE.DB
==============================

Tabela: calculations
    id (PK)
    calculation_hash (UNIQUE)
    input_structure_id (FK)
    output_structure_id (FK)
    energy
    convergence_steps
    convergence_params (JSON)
    calculation_method
    timestamp
    Índices: hash, input_id, output_id, timestamp

Tabela: execution_history
    id (PK)
    calculation_id (FK)
    machine
    wall_time
    xespresso_version
    qe_version
    execution_timestamp
    Índices: calculation_id, machine

Tabela: derivations
    id (PK)
    source_structure_id (FK)
    derived_structure_id (FK)
    derivation_method
    energy_change
    derivation_timestamp
    Índices: source_id, derived_id

Tabela: dependencies
    id (PK)
    calculation_id (FK)
    depends_on (FK)
    dependency_type
    reason
    Índices: calculation_id, depends_on


COMO USAR
=========

1. IMPORTAR:

    from xespresso.db import DatabaseWorkflow, get_structure_history

2. INICIALIZAR:

    db = DatabaseWorkflow()

3. EXECUTAR/CACHEAR:

    result, from_cache = db.get_or_calculate(
        atoms,
        {'protocol': 'moderate', 'machine': 'medusa'},
        calculation_method='scf'
    )

4. DERIVAÇÕES:

    db.log_structure_derivation(
        source_structure_id=1,
        derived_structure_id=2,
        derivation_method='vc-relax',
        energy_change=-0.123
    )

5. PROPRIEDADES EM ESTRUTURA OTIMIZADA:

    phonon, _ = db.run_properties_on_structure(
        structure_id=2,
        calc_type='phonon'
    )

6. ANÁLISE:

    history = get_structure_history(db.provenance, 2)
    df = export_to_dataframe(db.db, db.provenance)
    stats = get_calculation_stats(db.provenance)
