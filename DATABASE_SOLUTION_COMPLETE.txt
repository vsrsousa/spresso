PRINCIPAIS CARACTERÍSTICAS
==========================

1. CACHING AUTOMÁTICO
   ────────────────────
   - Hash calculado baseado em (estrutura + parâmetros QE)
   - Machine está fora do hash (pode usar resultado de qualquer máquina)
   - Primeira execução: calcula e armazena
   - Próximas execuções: retorna do cache em O(log n)

2. HERANÇA DE PARÂMETROS
   ──────────────────────
   - Relaxação armazena convergence_params
   - Phonon/Band/DOS herdam parâmetros automaticamente
   - Garante consistência científica
   - Validação automática de inconsistências

3. PROVENANCE TRACKING
   ───────────────────
   - Tabela: calculations (hash, energias, parâmetros)
   - Tabela: execution_history (máquina, tempo, versão)
   - Tabela: derivations (relação pai→filho de estruturas)
   - Tabela: dependencies (dependências entre cálculos)
   - Permite rastrear: quem calculou? onde? quando? como?

4. ANÁLISE EM LARGA ESCALA
   ───────────────────────
   - Export para pandas DataFrame
   - Filter por protocol, element, method
   - Queries otimizadas com índices SQLite
   - Escalável para ~10.000 cálculos

5. INTEGRAÇÃO TRANSPARENTE
   ───────────────────────
   - Funciona com CalculationWorkflow existente
   - Não quebra código antigo
   - API simples: get_or_calculate() + run_properties_on_structure()


COMO COMEÇAR A USAR
===================

1. Instalar (nada a fazer, já está no código)

2. Importar:
   
   from xespresso.db import DatabaseWorkflow
   from xespresso.db.queries import export_to_dataframe

3. Usar:
   
   # Inicializar
   db = DatabaseWorkflow()
   
   # Primeira execução
   result1, from_cache = db.get_or_calculate(
       atoms,
       {'protocol': 'moderate', 'machine': 'medusa'},
       calculation_method='scf'
   )
   
   # Segunda execução (mesmo cálculo)
   result2, from_cache = db.get_or_calculate(
       atoms,
       {'protocol': 'moderate', 'machine': 'medusa'},
       calculation_method='scf'
   )
   # from_cache = True ✅

PERFORMANCE
===========

Operações:
  - get_or_calculate() com cache hit: ~10ms (SQL query)
  - get_or_calculate() novo: ~10-1000s (depende do cálculo)
  - get_structure_history(): ~5ms
  - export_to_dataframe(1000 calcs): ~100-500ms
  - validate_consistency(): ~10ms

Escalabilidade:
  ✅ ~100 cálculos: Trivial
  ✅ ~1000 cálculos: Fácil
  ⚠️  ~10000 cálculos: OK com índices
  ❌ ~100000 cálculos: Considerar sharding
